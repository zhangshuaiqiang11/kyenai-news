# Cursor change-of-control review checklist

Verified: 2026-09-12

Use this checklist after the SpaceX-Anysphere merger closed, while teams review post-close product, privacy, model, and contract changes. It is an operational review aid, not legal advice.

## Current status

- [x] Definitive merger agreement signed on June 16, 2026.
- [x] Closing publicly confirmed in an official filing or company notice.
- [x] Exact closing date confirmed: August 14, 2026.
- [ ] Post-closing pricing, model, data-use, and contract changes confirmed.

## Inventory current dependencies

- [ ] Record Cursor plans, versions, models, extensions, and enabled preview features.
- [ ] List repositories, indexes, prompts, rules, agents, MCP servers, and automation jobs that depend on Cursor-specific behavior.
- [ ] Identify workflows that cannot currently move to another editor or coding agent.
- [ ] Record owners for procurement, security, privacy, legal, engineering, and incident response.

## Preserve the current evidence

- [ ] Archive the terms, privacy notice, data-use terms, security materials, DPA, and subprocessor list that apply to the account.
- [ ] Record retention, training, region, export, deletion, audit, and support commitments.
- [ ] Save the current billing plan and usage terms.
- [ ] Keep dated links or copies in the team's approved evidence system.

## Review change triggers

- [ ] Ask qualified counsel to review change-of-control, termination, renewal, export, and audit clauses.
- [ ] Define thresholds for unacceptable pricing, model availability, data handling, subprocessors, support, or policy changes.
- [ ] Assign an owner and due date for each trigger.
- [ ] Require evidence before treating rumors or product collaboration as proof of legal closing.

## Test portability

- [ ] Export or recreate repository instructions in a vendor-neutral source of truth.
- [ ] Run one representative task with a second coding-agent workflow.
- [ ] Compare setup time, verification results, permissions, review effort, and failure recovery.
- [ ] Confirm that code, prompts, logs, and repository context can be removed or migrated when required.

## Monitor

- [ ] Recheck the official SEC filing and merger agreement.
- [ ] Monitor official Cursor legal, security, data-use, pricing, and product notices.
- [ ] Recheck at closing, renewal, or any material policy change—whichever happens first.
- [ ] Document the final stay, mitigate, renegotiate, or migrate decision.
